# Данные классовых умений (SRD 5.1)

`srd-class-features.json` собран скриптом `scripts/import-foundry-class-features.py` из открытого
репозитория системы D&D 5e для Foundry VTT (https://github.com/foundryvtt/dnd5e, коммит указан в
`source.commit`). `srd-class-features-ru.json` — русские названия и краткие описания (правится вручную).
