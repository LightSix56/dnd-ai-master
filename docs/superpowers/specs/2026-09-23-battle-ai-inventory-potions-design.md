# Спецификация: Инвентарь, Зелья и Расходники в ИИ-Мастере и Тактическом Бою

## 1. Цель
Интегрировать систему инвентаря и официальных зелий D&D 5e из проекта листа персонажа (`dnd5e-character-sheet`) в проект ИИ-Мастера и тактического боя (`C:\antig\battle+ai`).

Пользователь должен иметь возможность:
1. **В тактическом бою (`Hotbar.tsx`, `CombatView.tsx`):**
   - Видеть кнопку с иконкой рюкзака `[🎒 Рюкзак]` в верхней панели хотбара со счетчиком зелий и отдельную вкладку `🎒 Зелья` в хотбаре.
   - Открывать меню расходников/зелий, видеть список доступных зелий, их количество, формулу и боевой эффект.
   - Использовать зелье кликом на кнопку «Выпить».
   - Использование зелья в бою стоит **СТРОГО 1 Бонусное действие** (`bonusActionUsed = true`).
   - Если бонусное действие уже потрачено в текущем раунде (`combatant.bonusActionUsed === true`), кнопка выпивания блокируется.
   - При употреблении зелья: рассчитывается бросок кубиков (лечение) или применяется состояние/бафф (временные ХП, благословение, ускорение), уменьшается количество зелья, создается запись в логе боя, синхронизируется инвентарь связанного персонажа.

2. **Вне боя в кампании (`CharacterCard.tsx`, `DnDApp.tsx`):**
   - На карточке персонажа игрока отображается кнопка рюкзака `[🎒]`.
   - По клику открывается модальное окно инвентаря персонажа (`CharacterInventoryModal`), разделенное на:
     - `🧪 Зелья и расходники`: список зелий с количеством и кнопкой «Выпить» (восстанавливает HP персонажа до максимума, списывает зелье и сохраняет в БД через `PATCH /api/character`).
     - `📦 Снаряжение и наборы`: список предметов из стартовых наборов путешественника/исследователя.
   - Передает события через `BroadcastChannel("dnd5e_character_sync")` для мгновенного обновления открытого листа в соседней вкладке браузера.

3. **Бэкенд и модель данных (`prisma/schema.prisma`, `types.ts`, `serialize.ts`, `generator.ts`, `api/combat/action/route.ts`, `api/character/route.ts`):**
   - Модель `Combatant`: поле `potions String @default("[]")` в Prisma, в TypeScript — массив `CombatPotion[]`.
   - При создании энкаунтера (`generator.ts`): боец получает зелья из `character.inventory` (или стартовые зелья лечения по умолчанию).
   - В `POST /api/combat/action`: экшен `drink-potion` с валидацией бонусного действия, броском лечения/наложением баффа и уменьшением количества.
   - В `PATCH /api/character`: сохранение полей `inventory` и `hpTemp`.

## 2. Глобальные ограничения
- Использование зелья в бою — **СТРОГО БОНУСНОЕ ДЕЙСТВИЕ**.
- Никакого хардкода: данные зелий берутся из структуры компендиума D&D 5e.
- Все подагенты вызываются на `Model: 'flash'`.
- Обязательный commit и push в Git перед завершением.
