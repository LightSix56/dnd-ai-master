# Процедурные карты для основных биомов и обводка стен

Дата: 2026-10-06. Статус: согласовано в чате. Продолжение
`2026-10-06-procedural-cave-maps-design.md` (пещера уже работает и не меняется).

## Зачем

Сейчас любой бой идёт в пещере, даже если по сюжету лес или город. Нужны генераторы карт
по зерну для основных биомов, с разметкой, совпадающей с артом. Отдельно: контуры стен на
тактическом слое рисуются вокруг каждого прямоугольника разметки и исчерчивают всю скалу.

## Что должно получиться

1. Бой получает карту своего биома, собранную по зерну; разметка и зоны появления — как у пещеры.
2. Биомы и генераторы:

| Биом (от мастера) | Генератор | Особенности |
|---|---|---|
| `cave` | пещера | как сейчас, без изменений |
| `lava` | пещера | вместо луж — лава (`lava`), тёплая подсветка |
| `dungeon` | подземелье | комнаты и коридоры, каменная плитка, кирпич, колонны, ящики |
| `tavern` | подземелье | деревянный пол, столы и стойка — укрытия, бочки |
| `forest` | природа | трава, деревья (ствол — препятствие), кусты, тропа, иногда ручей |
| `swamp` | природа | грязь и трава, много мелкой воды, камыш |
| `desert` | природа | песок, барханы, скалы, кактусы |
| `snow` | природа | снег, валуны, наледь, ели |
| `mountain` | природа | камень и снег, скальные гряды (стены), валуны |
| `coastal`, `ship` | природа | песчаный берег, море вдоль края, камни |
| `urban` | город | кварталы домов (стены), улицы, переулки, телеги и ящики, колодец |

   Неизвестный биом — пещера. Названия из старых пресетов (`forest_ambush`, `city_street`,
   `dungeon_prison`, `lava_cave` и т.п.) приводятся к биомам таблицы по ключевым словам.
3. Ссылка фона — `procgen:<биом>?seed=N&v=1`; существующие `procgen:cave?seed=N&v=1`
   рисуются как раньше.
4. На тактическом слое стены обводятся одной линией по границе со свободными клетками, для
   всех карт; препятствия — своей тонкой обводкой.

Что не входит: двери и окна, высоты, палуба корабля как отдельная карта, щебень в залах
пещеры остаётся как есть.

## Решение

### Общий план карты

`ProcgenLayout` — общий результат всех генераторов:
- `biome`, `seed`, `width`, `height` (24×16 клеток);
- `ground: Field` — 1 = можно стоять, 0 = сплошное (скала, стена, дом), субклеточное (SUB = 8);
- `liquid: Field` — вода или лава (тип жидкости задаёт биом);
- `decor: Decor[]` — объекты с координатами в клетках; вид объекта определяет разметку;
- `areas: Area[]` — места для зон появления (залы, комнаты, края открытой карты);
- `flankAreas: Area[]` — места засады (ниши, боковые края);
- `paths: Polyline[]` — проходы, коридоры, улицы, тропы (для прорезки связности клеток).

Пещера v1 переводится в `ProcgenLayout` адаптером без изменения своего плана и своей
разметки (`classifyCells` пещеры остаётся как есть — её фиксирует золотой тест).

### Разметка

Общая для всех биомов:
- `ground` < 0,5 в клетке → `wall`;
- жидкость ≥ 0,35 → `water` или `lava`;
- декор → тип клетки по таблице вида: дерево, колонна, скала, кактус, колодец —
  `obstacle`; валун, стол, стойка, ящик, телега, бочка — `cover`; куст, камыш, бархан,
  наледь, щебень — `difficult`; крона, тропа, трава — только арт;
- клетки вдоль `paths` прорезаются до пола с 4-связностью;
- соседние клетки одного типа склеиваются в прямоугольники.

### Зоны появления

Обобщение пещерных: пара `areas`, самых далёких по пути, — партия и враги; проверки: все
`areas` достижимы от партии, враги не ближе 8 шагов, засада (`flankAreas`) не ближе 4 и не в
зоне врагов, в каждой зоне ≥ 8 клеток. Провал — `seed + 1`, до 20 попыток. Препятствие
(`obstacle`) непроходимо так же, как стена.

### Отрисовка

`render-map.ts` — общий рисовальщик на canvas по палитре биома: две текстуры земли,
текстура и стиль сплошного (рельефная скала / кирпичная стена / крыша дома), жидкость
(вода / лава со свечением), рисовальщики декора по виду. Пещера рисуется им же. Текстуры —
`public/textures/cc0/` из того же CC0-набора; снег — тонировка; лава и вода — процедурно.

### Обводка стен

`CombatGrid`: для элементов `wall` вместо прямоугольника каждого элемента рисуются только
рёбра клеток стены, соседних со свободной клеткой; для `obstacle` — тонкий контур элемента.

## Тесты

Для каждого биома таблицы:
- одно зерно → одинаковая карта;
- 200 зёрен: путь от партии до врагов, враги ≥ 8 шагов, засада ≥ 4, зоны на полу, все
  элементы в границах, `areas` достижимы;
- золотой отпечаток плана и разметки (3 зерна);
- пещера: прежний золотой тест не меняется.

Обводка: чистая функция рёбер стены — тест на сетке 3×3.
Визуально: стенд со скриншотами всех биомов (по 2 зерна) пользователю.
