# Процедурные карты боя: пещера

Дата: 2026-10-06. Статус: согласовано в чате.

## Зачем

Готовых карт мало (11 картинок на 24 биома), а бесплатных карт с лицензией для публичного
сайта почти нет. Вместо готовых картинок бой получает карту, собранную на лету из
заготовленных частей по зерну, — каждая битва на новой карте, с разметкой, совпадающей с
артом. Начинаем с пещеры; остальные биомы — отдельными задачами после проверки в игре.

## Что должно получиться

1. При старте боя сервер собирает план пещеры по случайному зерну: стены, проходы, вода,
   укрытия, трудная местность, зоны появления.
2. План сохраняется как обычная разметка боя (`MapElement`) и зоны расстановки; фон боя —
   ссылка `procgen:cave?seed=<n>&v=1`.
3. Браузер каждого игрока по тому же зерну рисует арт на canvas; у всех игроков комнаты
   карта одинаковая.
4. Старые карты недоступны ИИ-мастеру и скриптам.

Что не входит: другие биомы, двери и окна, высоты, ручной редактор карт.

## Решение

### Модуль `src/lib/combat/procgen/`

Чистый TypeScript без DOM и canvas — один код на сервере и в браузере.

- `rng.ts` — генератор случайных чисел с зерном (mulberry32). `Math.random` в модуле не используется.
- `field.ts` — числовые поля субклеточного разрешения (8×8 отсчётов на клетку): шум, размытие, порог.
- `cave.ts` — `generateCaveLayout(seed, { width, height })` → `CaveLayout`:
  - залы (круглый, вытянутый, рваный), 2–4 штуки, разнесённые по карте;
  - проходы между залами по остовному дереву: узкий (1 клетка), широкий (2), извилистый;
  - 0–2 ниши-тупика;
  - детали: лужа, щебень в узких проходах, крупные валуны, сталагмиты;
  - поле пола `floor` (субклеточное), список декора с координатами.
- `markup.ts` — из `CaveLayout` клетки разметки:
  - доля пола в клетке < 0,5 → `wall`;
  - лужа ≥ 0,35 клетки → `water`;
  - крупный валун → `cover` (половинное);
  - щебень в проходе → `difficult`;
  - соседние клетки одного типа склеиваются в прямоугольники.
- `zones.ts` — зоны появления: `party` — дальний от врагов зал, `enemy_frontline` /
  `enemy_backline` — противоположный зал (ближняя и дальняя половины), `ambush_flank` — ниша.
- `index.ts` — `generateProcgenMap(biome, seed)` → `TacticalMapPreset` с
  `backgroundUrl = procgen:cave?seed=<n>&v=1`. Пока для любого биома возвращает пещеру.

Проверка плана: от зоны `party` до зоны врагов есть путь по проходимым клеткам (BFS); зоны
не пересекаются со стенами. Если проверка не прошла — берётся `seed + 1` (не более 20 попыток).

Размер карты: 24×16 клеток по умолчанию.

### Подключение к бою

- `generateEncounter` берёт карту из `generateProcgenMap(biome, seed)` вместо
  `getPresetById` / `getPresetByBiome`. Подбор монстров по биому не меняется.
- `createTacticalEncounter` перестаёт использовать `resolveBattlemapForNarrative` как
  запасной фон; разметка пишется одним `createMany`.
- Зерно — случайное на сервере при создании боя и хранится только в ссылке фона.

### Отрисовка в браузере

- `src/lib/combat/procgen/render-cave.ts` — `renderCaveToCanvas(layout, textures, cellPx)`:
  повторяет пробный рендер (текстуры пола, рельеф и затемнение скал, тень у стен, кромка,
  вода, валуны с тенями, виньетка). Использует `CanvasRenderingContext2D`.
- `CombatGrid` при `backgroundUrl`, начинающемся с `procgen:`, пересобирает план по зерну,
  рисует его в offscreen canvas, получает `blob:`-ссылку и подставляет в `<image href>`.
  Пока рисуется — показывается тёмный фон.
- Версия `v` в ссылке выбирает версию рисовальщика; при несовместимых изменениях генератора
  она увеличивается, старая ветка сохраняется.
- Текстуры — `public/textures/cc0/` (Screaming Brain Studios, Top Down Dungeon Pack, CC0) с
  `LICENSE.txt`; из автотайловых листов вырезаются ровные тайлы при подготовке ассетов.

### Старые карты

- `public/maps/*` переносится в `archive/maps/` (вне `public/`, сайт их не отдаёт).
- Каталог `OPEN_BATTLEMAP_CATALOG` и фон из пресетов больше не участвуют в создании боя;
  окно выбора карт перестаёт показывать старые карты.
- Код пресетов остаётся источником списка биомов.

## Тесты

- одно зерно → одинаковый план и одинаковая разметка;
- 200 зёрен: путь от `party` до врагов есть, зоны не на стенах, карта целиком в границах;
- хотя бы на части зёрен есть проход шириной ровно 1 клетка;
- `generateEncounter` возвращает карту со ссылкой `procgen:cave`;
- визуальная проверка: несколько зёрен отрисованы в браузере, скриншоты пользователю.
