# Дизайн: Парсинг базы 2014 (`dnd-shared`) и адаптация всех официальных рас и подрас под боевой движок

**Дата:** 2026-11-25
**Ветка разработки:** `dev` (основной репо), `main` (`dnd-shared`)
**Статус:** На согласовании

---

## 1. Контекст и цель

Проект объединяет два приложения на общей базе Supabase (`npcayouvvwjaqxqgxqxc`):
- **Сайт мастера** (`dnd-ai-master` / `ai_master_n_battle`) — тактический бой на сетке, ИИ-мастер, сетевые комнаты.
- **Сайт листа персонажа** (`dnd5e-character-sheet`) — конструктор и лист героя, где хранятся социальные, ролевые и боевые способности.
- **Общая библиотека** ([`dnd-shared`](https://github.com/LightSix56/dnd-shared)) — сейчас содержит только `data/spells.json` (525 заклинаний с `dnd.su`, 502 с полем `combat`).

Долгосрочная цель: перенести в `dnd-shared` все официальные данные D&D 5e редакции **2014 года** с `dnd.su` (без хоумбрю, UA и 2024) для обоих сайтов, и последовательно адаптировать все боевые механики под боевой движок.

Данная спецификация покрывает **Этап 1 — Расы и подрасы (2014, боевое масштабирование минимум до 10 уровня)**, а также единый контракт `dnd-shared` для всех последующих сущностей (`classes`, `feats`, `backgrounds`, `items`).

## 2. Источник истины и фильтрация контента

### 2.1. Что включается
- Только **D&D 5e (2014)** с `https://dnd.su/race/` и `https://dnd.su/multiverse/race/`.
- Официальные источники WotC:
  - **54 исходные расы и все их официальные подрасы**: `PH14`, `POA`, `VGM`, `MTF`, `GGR`, `AI`, `RLW`, `MOT`, `WBW`, `SCC`, `SDQ`, `VRGR`, `TCE`, `OGA`, `LR`, `TP`, `SAS`, включая официальные подрасы внутри базовых страниц (например, `FTD` / `EGW` / `SCAG` у драконорождённых, эльфов, дварфов, тифлингов, полуросликов, гномов).
  - **30 переизданий 2014 из `MPMM`** (*Mordenkainen Presents: Monsters of the Multiverse*) с отдельными идентификаторами (суффикс `-mpmm`, например `aasimar` и `aasimar-mpmm`).

### 2.2. Что строго исключается
1. Все карточки каталога с классом `tile-HB`: Homebrew (`HB*`), Unearthed Arcana (`UA`), Plane Shift (`PSA`, `PSIN`).
2. Любые материалы редакции **2024** (`PH24` и т.п.).
3. Встроенные секции `Unearthed Arcana` / `Homebrew` внутри официальных страниц (например, `Авариэль` и `Гругач` в разделе `Разновидности эльфов Unearthed Arcana` на `/race/79-elf/`).

## 3. Архитектура общего пакета `dnd-shared`

### 3.1. Единый принцип хранения сущностей
По образцу `data/spells.json` и `data/spells-core.json`:
- Полный файл `data/races.json` хранит полные данные с `dnd.su` (нарратив, социальные черты, языки, владения, возрасты, таблицы, варианты выбора, масштабирование, URL и источник) + декларативный блок `combat` для боевого движка.
- Облегчённый файл `data/races-core.json` вырезает внутренние поля боевого движка и используется сайтом листа (`dnd5e-character-sheet`) без лишнего веса.
- Обратная совместимость: сохраняются русские/английские названия и идентификаторы, совместимые с [`CompendiumRace`](file:///C:/antig/dnd5e-character-sheet/src/data/compendium/races/types.ts), плюс поле `aliases` для сопоставления вариативных написаний из старых листов (например, «Эльф (Высший)», «Высший эльф», «High Elf»).

### 3.2. Схема записи расы и подрасы (`Race` / `Subrace`)

```ts
export interface SpeedProfile {
  walk: number;
  fly?: number;
  swim?: number;
  climb?: number;
  burrow?: number;
  /** Полёт запрещён в среднем/тяжёлом доспехе (Ааракокра, Фэйри, Совлин) */
  flyNoHeavyOrMediumArmor?: boolean;
}

export interface RaceTrait {
  id: string;                 // латинский id, например "stone-endurance"
  name: string;
  nameEn?: string;
  description: string;        // чистый полный текст черты с dnd.su
  minLevel?: number;          // 1 по умолчанию, или 3 / 5 / 6 для масштабируемых черт
  combatRelevant: boolean;    // false для чистой социалки/лора/возраста/языков
  combat?: RaceTraitCombat;   // структурированные параметры для движка
}

export interface RaceProgressionStep {
  level: number;
  traitId: string;
  name: string;
  description: string;
  spell?: { name: string; nameEn?: string; level: number; castingAbilities?: ("INT" | "WIS" | "CHA" | "CON")[] };
  damageDice?: string;
  usesFormula?: "fixed" | "profBonus";
}
```

Для `dnd.su` пишется воспроизводимый парсер `C:\antig\dnd-shared\scripts\build-races.py`:
- Загружает индекс `https://dnd.su/race/`, фильтрует `tile-HB` и `PH24`, кеширует сырой HTML локально (чтобы последующие прогоны не дёргали сайт без необходимости).
- Парсит базовые характеристики (Увеличение характеристик, Размер, Скорости, Тёмное зрение, Языки, все черты `traits`, все официальные подрасы `subraces`, варианты вроде Наследия дракона/Мутаций Симиков/Сезонов эладрина).
- Извлекает русские и английские названия, код книги `sourceBook`, `dndsuUrl`, строит детерминированные id и `aliases`.
- Прогоняет валидацию: количество официальных рас === 84 (54 Legacy + 30 MPMM), 0 UA/HB/Plane Shift, ни одна черта без описания, JSON-схема проверена тестом `node --test test/races.test.js`.

### 3.3. Экспорты `dnd-shared`
В `package.json` (`exports`), `src/index.js` и `src/index.d.ts` добавляются:
- `./races.json` -> `./data/races.json`
- `./races-core.json` -> `./data/races-core.json`
- `RACES: Race[]`
- `findRace(raceQuery: string, subraceQuery?: string): { race: Race; subrace?: Subrace } | undefined`

## 4. Архитектура боевого движка (`ai_master_n_battle`)

Расы подключаются по тому же принципу, что и `classes/`: **минимум правок в `engine.ts`, максимум декларативности через `feature-mods.ts`, `class-kit.ts` и `class-hooks.ts`**.

### 4.1. Проброс расы и характеристик в `Combatant`
1. В [`Combatant`](file:///c:/antig/ai_master_n_battle/src/lib/combat/types.ts#L16-L68) добавляются опциональные поля:
   - `race?: string`
   - `subrace?: string`
   - `raceId?: string`
   - `subraceId?: string`
   - `darkvision?: number` (футы: 0 / 60 / 120)
   - `speeds?: { fly?: number; swim?: number; climb?: number; burrow?: number }`
   - `racialVariants?: string[]` (выбранный предок дракона, сезон фей, мутации гибрида Симиков, заклинательная характеристика MPMM)
2. Все три точки создания бойца синхронизируются через единый адаптер `resolveRaceForCombatant(char)` в `src/lib/combat/character-adapter.ts`:
   - `createPartyCombatants` (`src/lib/combat/generator.ts`)
   - `POST /api/combat/import-character` (`src/app/api/combat/import-character/route.ts`)
   - тестовый harness `raceHero()` / `classHero()` (`src/lib/combat/__tests__/helpers/race-harness.ts`)
3. Адаптер заполняет на бойце:
   - расовые способности `CombatAbility` (с корректным `srdKey` вида `race/<raceId>/<traitId>` или `race/<subraceId>/<traitId>`, масштабом до 10+ ур., зарядами и спасбросками);
   - врождённые расовые заклинания (не тратят классовые ячейки, учитываются как отдельные заряды `1/long` или через `SpellData` / `CombatAbility` с корректной базовой характеристикой: ХАР/МУД/ИНТ на выбор для MPMM или фиксированной для Legacy);
   - естественное оружие (`Когти`, `Укус`, `Рога`, `Клюв` и т.д.), если оно ещё не добавлено вручную на лист;
   - базовые сопротивления/иммунитеты (например, сопротивление огню тифлинга, некротике/излучению аасимара, холоду голиафа/тритона, урону предка драконорождённого), размер и скорости.

### 4.2. Слой правил и хуков `src/lib/combat/races/`
Структура модуля повторяет `src/lib/combat/classes/`:
- `src/lib/combat/races/race-defs.ts` — реестр `defineRace`, нормализация и резолвер `resolveRaceFeatures(ctx)` по данным из `dnd-shared` + ручным правилам (аналог `class-defs.ts`: `skip`, `passive`, `active`, `pool`, `uses`, `save`, `dc`, `offTurn`).
- `src/lib/combat/races/core-phb.ts` + `core-phb-combat.ts` — все расы и подрасы PHB + их официальные подрасы из MTF/SCAG/RLW/FTD/EGW (`human`, `dwarf`, `elf`, `halfling`, `dragonborn`, `gnome`, `half-elf`, `half-orc`, `tiefling`).
- `src/lib/combat/races/legacy-volo-mtf.ts` + `-combat.ts` — расы VGM/MTF/POA/TCE/VRGR (`aasimar`, `bugbear`, `firbolg`, `genasi`, `gith`, `goblin`, `goliath`, `hobgoblin`, `kenku`, `kobold`, `lizardfolk`, `orc`, `tabaxi`, `triton`, `yuan-ti-pureblood`, `aarakocra`, `dhampir`, `hexblood`, `reborn`, `custom-lineage`).
- `src/lib/combat/races/legacy-settings.ts` + `-combat.ts` — сеттинговые и приключенческие расы (`GGR`, `AI`, `RLW`, `MOT`, `WBW`, `SCC`, `SDQ`, `SAS`, `OGA`, `LR`, `TP`).
- `src/lib/combat/races/mpmm.ts` + `mpmm-combat.ts` — все 30 рас `MPMM` (`*-mpmm`).
- `src/lib/combat/races/rules-index.ts` и `combat-index.ts` — единые точки подключения в `rules.ts` и `class-hooks.ts`.

### 4.3. Расширения базовых примитивов движка (`feature-mods.ts`, `rules.ts`, `engine.ts`)
Только общие переиспользуемые механики без привязки к конкретным расам:
1. **Переброс `1` на к20 (`rerollOnes` в `Mods`)** — Везучий полурослик перебрасывает выпавшую 1 на броске атаки и спасброске (в `rules.ts`).
2. **Условное преимущество/иммунитет спасбросков (`saveAdvantageConditions` / `magicSaveAdvantage` в `Mods`)**:
   - преимущество против `charmed` + иммунитет к магическому усыплению (Фейское наследие);
   - преимущество против `poisoned` (Дварфийская стойкость / Стойкость коренастых полуросликов);
   - преимущество против `frightened` (Храбрый полурослик, Леонин);
   - преимущество на спасброски ИНТ/МУД/ХАР против магии (`Гномья хитрость`, `Бесстрастие ведалкена`);
   - сопротивление магии (`Сатир`, `Юань-ти`): преимущество на спасброски против заклинаний и других магических эффектов.
3. **Удержание на 1 хите (`onDrop` через `registerKit`)** — *Непоколебимая стойкость* полуорка / орка MPMM (`1/длинный отдых`, не срабатывает от мгновенной смерти).
4. **Снижение урона с броском кости и модификатором (`reductions` в `ClassKit`)** — *Каменная выносливость* голиафа (`1d12 + ТЕЛ`), автоматически предлагает игроку окно [`ReactionPrompt`](file:///c:/antig/ai_master_n_battle/src/lib/combat/reactions.ts) через уже существующий `scoped()` в `class-hooks.ts`.
5. **Ограниченный по уровню масштаб и бонус инициативы/скрытности/дистанции/КД**:
   - *Боевое искусство/дыхание драконорождённого* (PHB `2d6` на 1 ур. -> `3d6` на 6 ур., конус/линия; FTD Хроматический/Металлический/Самоцветный `1d10` -> `2d10` на 5 ур. + доп. способности на 5 ур.);
   - *Аасимар* (Исцеляющие ладони; на 3 ур. стойки Преображения: Сияющая душа / Сияющий саван / Некротический саван — полёт, аура урона, +уровень к урону раз в ход);
   - *Вне-ходовые и ходовые расовые действия*: Шаг фей (Эладрин, с эффектами сезонов), Скрытый шаг (Фирболг), Неистовый напор / Рывок адреналина (Орк), Ярость мелкого (Гоблин, бонус = уровень или БМ в MPMM), Умное бегство (Гоблин — Отход/Засада бонусным), Внезапная атака (Багбир +2d6 по не ходившему в первом раунде), Смена облика/Шифтинг (Шифтер — временные хиты + эффекты подтипов), Кровососущий укус (Дампир), Голодные челюсти (Людоящер), Устрашающий рёв (Леонин), Спусковой крючок кролика (Зайцегон — +БМ к инициативе, Кроличий прыжок), Пробуждённый разум / Телепортация / Ментальный бросок.
6. **Пассивные расовые поправки КД и хитов**:
   - Если у бойца не зафиксирован более высокий доспех на листе (`armorClass`), адаптер учитывает базовый расчёт естественного панциря/чешуи (Тортл КД 17, Локсодон `12 + ТЕЛ`, Ящеролюд `13 + ЛОВ`, Автогном `13 + ЛОВ`, Кованый `+1` к КД);
   - Холмовой дварф: `+1` хит за уровень проверяется при адаптации/аудите (без двойного начисления, если лист уже включает бонус).
7. **Врождённая магия до 10 уровня**:
   - Заговоры с 1 ур. (Высший эльф, Лесной эльф/Морозный/Огненный и т.д., Тифлинг — Тауматургия, Юань-ти, Генази, Аасимар, Астральный эльф и др.) + заклинания 3 ур. и 5 ур. (Адское возмездие 2 круга и Тьма у Тифлинга, Огонь фей и Тьма у Дроу, Невидимость и Увеличение/уменьшение у Дуэргара, Туманный шаг, Проход без следа, Левитация и т.д.).
   - Реализуются через универсальную обёртку врождённых расовых заклинаний поверх уже существующих заклинаний из `dnd-shared` (`SPELL_LIBRARY`), чтобы не дублировать логику спелл-движка.

### 4.4. Небоевые и социальные черты
- Черты без боевого эффекта (`Транс`, `Знание камня`, `Мастерство кузнеца`, `Искусство ремесла`, `Языки`, `Дипломатия`, `Подражание`, `Кошачья грация` и т.п.) **не замусоривают боевой хотбар** — в правилах боя они помечаются `kind: "skip"` (с полным сохранением в `dnd-shared/data/races.json` и `races-core.json` для второго сайта и ИИ-мастера).
- Сомнительные пограничные черты (например, *Стойкость против усыпления* у Транса эльфов, *Задержка дыхания*, *Тёмное зрение*) обрабатываются движком там, где это влияет на правила боя (сон, видимость в темноте, вода/удушье).
